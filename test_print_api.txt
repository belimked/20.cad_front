# 直接测试 /api/v1/tasks/print 接口

## PowerShell 命令：

$body = @{
    dwg_url = "F:/cad/caddd/PCX20.01 主体钢结构（20230301）.dwg"
    config_name = "bplot"
    use_bplot = $true
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:8000/api/v1/tasks/print" -Method POST -Body $body -ContentType "application/json"

## 或者使用 curl：

curl -X POST "http://localhost:8000/api/v1/tasks/print" -H "Content-Type: application/json" -d "{\"dwg_url\": \"F:/cad/caddd/PCX20.01 主体钢结构（20230301）.dwg\", \"config_name\": \"bplot\", \"use_bplot\": true}"

## 查询任务状态：

# 拿到返回的 task_id 后
curl "http://localhost:8000/api/v1/tasks/{task_id}"

## 或者浏览器访问：

http://localhost:8000/docs
点击 /api/v1/tasks/print -> Try it out
