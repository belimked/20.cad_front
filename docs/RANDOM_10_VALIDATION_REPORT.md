## ⚠️ 发现的问题

### 1. 人员信息误识别（严重）

**问题描述**:
- 设计/审核/批准字段被误识别为重量数据
- 示例: "121.3"、"3181.2"、"材料："、"V1.0"等

**原因分析**:
- 位置判断策略：基于"设计"/"审核"关键词右侧的文本
- "重量/Kg"字段恰好在同一位置
- 过滤规则不够严格

**影响程度**: 🔴 高（人员信息不可用）

**解决方案**:
```python
# 增强过滤规则
invalid_patterns = [
    r'^\d+\.?\d*$',      # 纯数字
    r'.*材料.*',         # 包含"材料"
    r'^V\d+\.\d+$',      # 版本号
    r'.*[/:].*',         # 包含特殊符号
]
```

### 2. 公司信息前缀字符（中等）

**问题描述**:
- 部分公司名称有前缀字符
- 示例: "Z深圳市奇贝科技"、"乙深圳市奇见科技"

**原因分析**:
- OCR识别到公司名称前的额外字符
- 可能是图纸上的编号或标记

**影响程度**: 🟡 中等（可后处理清理）

**解决方案**:
```python
# 清理前缀
company = company.lstrip('Z乙甲丙丁')
```

### 3. 图号末尾字符（轻微）

**问题描述**:
- 1个图号末尾多"`-`"字符
- 示例: "CX9-01-02-14-"

**原因分析**:
- 原始图号不完整或被截断

**影响程度**: 🟢 轻微（1/10，可接受）

**解决方案**:
```python
# 清理末尾
drawing_no = drawing_no.rstrip('-')
```

### 4. BOM表字段缺失（中等）

**问题描述**:
- BOM表能识别存在，但部分字段缺失
- 平均只提取1.8项/图（实际应该更多）

**原因分析**:
- 列边界判断依赖固定坐标
- 不同图纸的表格布局略有差异

**影响程度**: 🟡 中等（装配图需要）

**解决方案**:
- 使用表头动态定位列边界
- 放宽坐标容差
