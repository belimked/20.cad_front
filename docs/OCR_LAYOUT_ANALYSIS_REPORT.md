## 🎯 发现的规律

### 1️⃣ **页面布局统一规律** ✅

**所有图纸的标准布局**:

```
┌─────────────────────────────────────┐
│  TOP 区域 (Y: 0-450)                │  ← 图纸标题、部分尺寸标注
│  - 少量文字（0-20个）                │
│  - 主要是尺寸、标注                  │
├─────────────────────────────────────┤
│  MIDDLE 区域 (Y: 450-800)           │  ← 图纸主体区域
│  - 通常无文字（图形为主）            │
│  - 复杂装配图可能有标注              │
├─────────────────────────────────────┤
│  BOTTOM 区域 (Y: 800-1200)          │  ← 标题栏 + 技术要求
│  - 密集文字（20-50个）               │
│  - 包含技术要求、零件表、标题栏      │
└─────────────────────────────────────┘
```

**规律**:
- ✅ **BOTTOM区域文字密度最高** - 所有文件的73.6%文字都在这个区域
- ✅ **MIDDLE区域通常为空** - 这是图形主体区域
- ✅ **标题栏位置固定** - 都在Y≈1000-1200范围

### 2️⃣ **图纸类型识别规律** ✅

根据文字块数量可以区分图纸类型：

**A类：复杂装配图** (文字块 ≥ 70)
- 示例：文件0001（88个）
- 特征：
  - 包含完整零件BOM表（10+ 行）
  - 包含详细技术要求（5个段落）
  - TOP/MIDDLE区域有大量尺寸标注（37个）
  - 表格列数多（9列）

**B类：简单零件图** (文字块 20-40)
- 示例：文件0010, 0050, 0100, 0150
- 特征：
  - 只有标题栏信息（6-8行）
  - 简单技术要求（1-3条）
  - TOP/MIDDLE区域文字极少（0-10个）
  - 表格列数少（2-4列）

**识别规则**:
```python
if text_blocks >= 70:
    type = "装配图/总图"
elif 20 <= text_blocks < 70:
    type = "零件图"
else:
    type = "简图"
```

### 3️⃣ **技术要求位置规律** ✅

**固定位置**: Y ≈ 1080-1160 范围

**识别特征**:
- 文字开头："技术要求："
- 后续有编号："1.", "2.", "3."等
- 文字长度：通常 ≥ 20字符
- 宽度：250-450像素

**实际示例**:

|-----|------------|-----------|
| 0001 | 5条 | 127-310 |
| 0010 | 2条 | 1080-1125 |
| 0050 | 3条 | 1066-1110 |
| 0100 | 2条 | 1066-1095 |
| 0150 | 2条 | 1066-1095 |

**规律**: 零件图的技术要求通常在Y≈1066-1125，装配图可能更靠上（Y≈127-310）

### 4️⃣ **标题栏表格规律** ✅

**横向对齐（表格行）**:

**所有文件的共同表格行**:
```
行1: 序号 | 图号 | 名称 | 数量 | 备注    (Y≈1035)
行2: 标记 | 设计 | 审核 | 批准             (Y≈1095-1110)
行3: 修改日期 | 重量/Kg | 版号 | 比例     (Y≈1125-1140)
```

**纵向对齐（表格列）**:

**固定列位置**:
- 列1: X≈1065 → "设计 → 审核 → 批准"
- 列2: X≈1170 → "修改日期 → 重量/Kg → 版号 → 比例"

**规律**: 标题栏格式高度统一，可以用固定坐标范围提取

### 5️⃣ **特殊信息提取规律** ✅

**图号识别**:
- 格式：`PCX[数字]-[数字]-[数字]-[数字]-[数字]`
- 位置：X≈1170-1580, Y≈900-1150
- 准确率：100%（6/6个文件都识别成功）

**材料标识**:
- 常见值：Q235B, Q345B, 30mm厚钢板
- 位置：X≈1580-1650, Y≈880-1010
- 出现频率：装配图多次出现，零件图1-2次

**公司信息**:
- 固定文字："深圳市奇见科技有限公司"
- 位置：Y≈1060-1080
- 识别率：100%

### 6️⃣ **尺寸标注分布规律** ⚠️

**分布特征**:
- 主要在TOP区域（Y < 450）
- 通常是单个数字或简单数字组合
- 置信度普遍较低（26%-92%不等）
- 装配图尺寸标注多，零件图少

**问题**:
- 很多单字符数字（"0", "2", "5"等）难以理解含义
- 部分识别错误（如"田"、"击"、"to"等误识别）

### 应用1: 自动分类图纸

```python
def classify_drawing(text_blocks_count):
    """根据文字块数量自动分类图纸"""
    if text_blocks_count >= 70:
        return {
            'type': '装配图/总图',
            'extract': ['零件BOM表', '详细技术要求', '装配关系']
        }
    elif text_blocks_count >= 20:
        return {
            'type': '零件图',
            'extract': ['标题栏', '简单技术要求', '零件参数']
        }
    else:
        return {
            'type': '简图',
            'extract': ['标题栏']
        }
```

```python
def extract_by_region(items):
    """按区域提取不同信息"""

    # BOTTOM区域 (Y > 800) - 提取结构化信息
    title_block = [item for item in items
                   if get_center(item['box'])[1] > 800]

    # 技术要求子区域 (Y: 1060-1160)
    tech_requirements = [item for item in title_block
                         if 1060 <= get_center(item['box'])[1] <= 1160
                         and len(item['text']) >= 20]

    # 标题栏表格 (Y: 900-1050)
    table_data = [item for item in title_block
                  if 900 <= get_center(item['box'])[1] <= 1050]

    return {
        'tech_requirements': tech_requirements,
        'table_data': table_data
    }
```

### 应用3: 提取标题栏信息

```python
def extract_title_block(items):
    """提取标题栏固定字段"""

    # 按固定坐标范围提取
    fields = {
        'drawing_number': None,  # X: 1170-1270, Y: 900-1000
        'part_name': None,       # X: 1300-1400, Y: 900-1000
        'material': None,        # X: 1580-1650, Y: 880-1010
        'company': None,         # Y: 1060-1080, 包含"公司"
        'scale': None,           # X: 1200-1300, Y: 1150-1170
        'weight': None,          # X: 1200-1300, Y: 1120-1140
    }

    for item in items:
        center_x, center_y = get_center(item['box'])
        text = item['text']

        # 图号
        if 1170 <= center_x <= 1270 and 900 <= center_y <= 1000:
            if 'PCX' in text and '-' in text:
                fields['drawing_number'] = text

        # 材料
        if 1580 <= center_x <= 1650 and 880 <= center_y <= 1010:
            if 'Q235B' in text or 'Q345B' in text:
                fields['material'] = text

        # 公司
        if 1060 <= center_y <= 1080 and '公司' in text:
            fields['company'] = text

    return fields
```

### 应用4: 识别零件BOM表

```python
def extract_bom_table(items):
    """识别并提取零件BOM表（仅装配图）"""

    # 检测表头行 (包含"序号"、"图号"、"名称"等)
    header_row = None
    for item in items:
        if '序号' in item['text'] or '图号' in item['text']:
            header_row = get_center(item['box'])[1]
            break

    if not header_row:
        return []  # 无BOM表

    # 提取BOM数据行（表头下方20-200像素范围）
    bom_rows = []
    tolerance = 15

    # 按Y坐标分组
    y_groups = defaultdict(list)
    for item in items:
        center_y = get_center(item['box'])[1]

        # 在表头下方范围内
        if header_row + 20 <= center_y <= header_row + 200:
            y_key = round(center_y / tolerance) * tolerance
            y_groups[y_key].append(item)

    # 筛选表格行（至少4个字段）
    for y, group in sorted(y_groups.items()):
        if len(group) >= 4:
            # 按X坐标排序
            group.sort(key=lambda x: get_center(x['box'])[0])

            row_data = {
                'number': None,      # 序号
                'drawing_no': None,  # 图号
                'name': None,        # 名称
                'material': None,    # 材料
                'quantity': None     # 数量
            }

            for item in group:
                text = item['text']
                x = get_center(item['box'])[0]

                # 根据X坐标判断列
                if x < 1100:
                    row_data['number'] = text
                elif 1100 <= x < 1300 and 'PCX' in text:
                    row_data['drawing_no'] = text
                elif 1300 <= x < 1500:
                    row_data['name'] = text
                elif x >= 1580:
                    if 'Q235B' in text or 'Q345B' in text:
                        row_data['material'] = text
                    elif text.isdigit():
                        row_data['quantity'] = int(text)

            if row_data['drawing_no']:  # 至少有图号
                bom_rows.append(row_data)

    return bom_rows
```

## 🔍 待优化问题

### 1. 尺寸标注识别

**问题**: 单个数字意义不明，需要结合位置和图形理解

**建议**:
- 暂不提取尺寸标注文字
- 或者结合图形识别（引线、标注线）

### 2. 特殊符号识别

**问题**: `±`被识别为"土"或"士"

**建议**:
- 后处理替换：`土` → `±`, `士` → `±`
- 或使用专业工程图纸OCR引擎

### 3. 识别置信度差异

**问题**: 文件0001置信度(80.9%)低于其他文件(85-90%)

**原因**: 装配图内容复杂，小尺寸标注多

**建议**:
- 按文字块长度过滤：只提取长度≥3的文字
- 或按置信度过滤：只保留置信度>70%的

2. ✅ **标题栏格式统一** - 所有文件的标题栏位置和格式高度一致

### 中等置信度规律（需验证）

1. ⚠️ **BOM表结构** - 装配图包含零件表，但格式需进一步验证
2. ⚠️ **尺寸标注位置** - TOP区域文字多为尺寸，但含义不明

1. ❌ **图纸主体区域** - MIDDLE区域文字极少且无规律
