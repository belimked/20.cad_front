# AutoCAD PDF导出 - 保留文字设置指南

## 问题
当前PDF文件中的文字被转为矢量路径，无法直接提取，必须使用OCR

## 解决方案

### 方案1: 修改PC3打印配置文件

#### 步骤1: 打开打印配置管理器
```
方法1: 命令行输入 PLOTTERMANAGER
方法2: 文件菜单 → 打印机管理器
方法3: 直接打开文件夹: C:\Users\用户名\AppData\Roaming\Autodesk\AutoCAD 2014\R19.1\chs\Plotters
```

#### 步骤2: 编辑或创建PC3文件
1. 双击现有的 `DWG To PDF.pc3`
2. 或右键 → 新建 → 添加打印机向导

#### 步骤3: 关键配置项

**位置**: 设备和文档设置标签

```
图形 → 矢量图形 → 自定义属性
├─ TrueType字体
│  ├─ ❌ 几何图形 (当前设置 - 文字变路径)
│  ├─ ✅ 文本 (推荐 - 保留文字对象)
│  └─ ✅ Unicode文本 (最佳 - 支持中文)
│
├─ 捕获文本
│  └─ ✅ 启用文本捕获
│
└─ 字体嵌入
   └─ ✅ 嵌入TrueType字体
```

#### 步骤4: 保存配置
```
另存为: DWG To PDF - WithText.pc3
位置: Plotters文件夹
```

---

### 方案2: 通过AutoLISP命令设置

在AutoCAD命令行运行：

```lisp
; 设置PDF打印配置
(setenv "PDFTextOption" "1")  ; 1=保留文字, 0=转为路径

; 或通过系统变量
(setvar "PDFSHX" 1)  ; 1=作为文字, 0=作为几何图形
```

---

### 方案3: 批量打图精灵设置

如果使用第三方打图工具，查找以下设置：

```
工具界面中查找:
├─ PDF选项/PDF设置
├─ 高级选项/导出设置
└─ 文字质量/字体选项

关键选项:
✅ 保留文字对象
✅ 文字作为文本
✅ 嵌入字体
❌ 文字转曲线
❌ 文字转为路径
❌ 文字光栅化
```

---

### 方案4: 使用EXPORT命令而非PLOT

```
AutoCAD命令行:
EXPORTPDF

设置:
- 文件格式: PDF
- 文字选项: 保留为文字
- 质量: 高
```

```

```


## 测试方法

修改设置后，打印一个测试文件，然后运行：

```bash
# 测试文字提取
pdftotext test.pdf - | head -20

# 如果看到文字内容 = 成功！
# 如果仍然是空 = 设置未生效
```

## 注意事项

### 优点
✅ 可搜索文字
✅ 可复制粘贴
✅ 文件更小
✅ 无需OCR
✅ 加载更快

### 缺点
⚠️ 依赖字体（接收方需要有相同字体）
⚠️ 不同电脑显示可能略有差异
⚠️ 可能遇到字体替换问题

### 最佳实践
如果PDF用于：
- 存档、打印: 文字转路径 (当前方式)
- 数据分析、搜索: 保留文字 (修改后)
- 两者兼顾: 同时生成两个版本
