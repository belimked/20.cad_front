步骤1: 打开配置管理器
    AutoCAD命令行 → PLOTTERMANAGER → 回车

步骤2: 找到并编辑PC3文件
    双击 "DWG To PDF.pc3"

步骤3: 导航到设置位置
    设备和文档设置 (标签页)
      → 图形 (展开)
        → 矢量图形 (展开)
          → 自定义属性 (点击按钮)

步骤4: 修改设置
    ┌────────────────────────────────┐
    │ TrueType字体:                  │
    │   ◉ Unicode文本  ← 点这里！    │
    │   ○ 文本                       │
    │   ○ 几何图形                   │
    │   ○ 不捕获                     │
    │                                │
    │ ☑ 捕获文本      ← 勾选！       │
    │ ☑ 嵌入TrueType字体 ← 勾选！    │
    └────────────────────────────────┘

步骤5: 保存配置
    确定 → 保存并关闭

步骤6: 测试单个文件
    打印1个DWG文件到PDF → 用验证脚本测试

步骤7: 确认成功后批量处理
    重新生成所有183个PDF文件

【常见错误】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 选择了"不捕获"
   → 含义: 不捕获为文本，作为几何处理
   → 结果: 文字变路径，无法提取

❌ 没有勾选"捕获文本"
   → 结果: 文本对象被忽略

❌ 没有勾选"嵌入TrueType字体"
   → 结果: 接收方可能看不到正确字体

❌ 修改了PC3但AutoCAD未选用
   → 打印时检查打印机名称是否正确

❌ 只修改了PC3，未重新生成PDF
   → 旧PDF不会自动更新，必须重新打印

如何判断PDF是否正确？

✅ 正确的PDF:
   - pdffonts显示3个以上字体
   - pdftotext能提取完整文字
   - PDF查看器能选中文字
   - 文件大小相对较小(80-100KB)

❌ 错误的PDF:
   - pdffonts显示0个字体或报错
   - pdftotext输出为空
   - PDF查看器不能选中文字
   - 文件大小相对较大(120-150KB)
