# CAD 文件处理前端项目

## 项目概述

这是一个基于 Tauri 的桌面前端应用，用于 CAD 文件的上传、处理和预览。

## 技术栈

- **框架**: Tauri (跨平台桌面应用框架)
- **前端**: (待确定: React/Vue/Svelte)
- **语言**: Rust (后端) + TypeScript/JavaScript (前端)

## 核心功能

### 1. 文件上传
- 支持 DWG/DXF 等 CAD 文件格式上传
- 拖拽上传支持
- 批量文件上传
- 上传进度显示

### 2. 远程接口调用
- 调用后端 API 提交处理任务
- 处理任务提交和管理
- 错误处理和重试机制

### 3. 状态进度显示
- 实时显示任务处理状态
- 进度条和百分比显示
- 多任务并行状态监控
- 任务日志和详情查看

### 4. 远程下载链接获取
- 获取处理完成的文件下载链接
- 支持批量下载
- 下载进度追踪

### 5. 在线 PDF 预览
- 集成 PDF 查看器
- 支持缩放、旋转、翻页
- 多页 PDF 导航
- 打印和下载功能
