# AutoCAD PDF导出 - 正确配置指南

## 问题诊断

**当前状态：**
- ❌ PDF无字体资源（Font: 0个）
- ❌ 文字被完全转为矢量路径
- ❌ pdftotext无法提取任何文字

**原因：**
用户将设置改为"不捕获"，这是**错误**的！

---

## 正确配置步骤

### 关键设置位置

在AutoCAD **"DWG To PDF特性"** 对话框中：

```
设备和文档设置 → 图形 → 矢量图形 → 自定义属性
```

### ❌ 错误设置（当前）

```
TrueType字体处理：
  ❌ 几何图形 (Geometry) ← 旧设置
  ❌ 不捕获 ← 新设置（仍然错误！）
```

**"不捕获"的含义：** 不捕获为文本对象，而是作为几何图形处理

### ✅ 正确设置（应该修改为）

```
TrueType字体处理：
  ✅ 文本 (Text)  ← 推荐：保留为文本对象
  ✅ Unicode文本 (Unicode Text) ← 最佳：支持中文
```

## 配置步骤详解

### 方法1：修改PC3配置文件（推荐）

#### 步骤1：打开打印配置管理器
```
方法A: 命令行输入 PLOTTERMANAGER
方法B: 文件 → 打印机管理器
方法C: 直接打开文件夹：
       C:\Users\用户名\AppData\Roaming\Autodesk\AutoCAD 2014\R19.1\chs\Plotters
```

#### 步骤2：编辑PC3文件
1. 找到 `DWG To PDF.pc3`
2. 双击打开 **打印机配置编辑器**

#### 步骤3：关键配置项

**导航路径：**
```
设备和文档设置（标签页）
  → 图形
    → 矢量图形
      → 自定义属性（点击按钮）
```

**在弹出的对话框中设置：**

```
┌─────────────────────────────────────────┐
│ DWG To PDF特性                          │
├─────────────────────────────────────────┤
│                                         │
│ TrueType字体：                          │
│   ◉ Unicode文本  ← 选择这个！           │
│   ○ 文本                                │
│   ○ 几何图形                            │
│   ○ 不捕获                              │
│                                         │
│ ☑ 捕获文本                              │
│ ☑ 嵌入TrueType字体                      │
│                                         │
└─────────────────────────────────────────┘
```

#### 步骤4：保存配置
```
点击"确定"关闭对话框
点击"保存并关闭"或"另存为"
建议另存为: DWG To PDF - Unicode.pc3
```

#### 步骤5：在AutoCAD中使用新配置
```
打印 → 打印机/绘图仪名称 → 选择 "DWG To PDF - Unicode.pc3"
```

---

### 方法2：每次打印时手动设置

1. **打印** (Ctrl+P)
2. 选择打印机：**DWG To PDF.pc3**
3. 点击 **特性** 按钮
4. 导航到：**设备和文档设置 → 图形 → 矢量图形 → 自定义属性**
5. 设置：**TrueType字体 → Unicode文本**
6. **勾选** ☑ 捕获文本
7. **勾选** ☑ 嵌入TrueType字体
8. 点击 **确定** → **应用到布局** → **打印**

## 常见问题

### Q1: "Unicode文本"和"文本"有什么区别？
**A:**
- **文本**：使用ANSI编码，可能不支持中文
- **Unicode文本**：完全支持中文、日文等多字节字符（推荐）

### Q2: 为什么文件变小了？
**A:**
- 文字作为路径时，每个笔画都是独立的矢量对象
- 文字作为文本时，只存储字符+字体引用，数据量更小

### Q3: 接收方能正确显示吗？
**A:**
- 如果勾选了 ☑ 嵌入TrueType字体：✅ 可以
- 如果没有嵌入：⚠️ 需要接收方有相同字体

### Q4: 会影响打印质量吗？
**A:**
- 不会！PDF查看器会用嵌入的字体正确渲染
- 打印机会按照字体轮廓高质量输出

## 注意事项

### ⚠️ 重要提醒

1. **必须重新生成PDF**
   - 修改配置后，需要**重新打印**所有文件
   - 已生成的PDF不会自动更新

2. **测试单个文件**
   - 先打印1个文件测试
   - 确认文字可提取后再批量处理
   - 避免重复生成183个错误文件

3. **PC3文件位置**
   - 修改的PC3文件会保存在Plotters目录
   - 确保AutoCAD使用的是修改后的配置

4. **批量打图工具**
   - 如果使用第三方工具，确保工具调用了正确的PC3配置
   - 或在工具中查找"PDF文字设置"选项
