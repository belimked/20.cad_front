## 🔍 发现的问题

### 1. 图号不完整（3个）

**问题**: 部分图号以"-"结尾，说明被截断
- 示例: `PCX9-01-01-01-`, `PCX9-01-02-01-`

**原因**:
- 可能是图号跨行显示
- 或OCR识别边界问题

**影响**: 轻微，大部分图号仍可识别

**建议**: 放宽图号识别的X坐标范围

### 2. 人员信息误识别（多个）

**问题**: "设计"字段出现数字或无关文字
- 示例: `64.76`, `0.75`, `121.3`（实际是重量）

**原因**:
- 位置判断逻辑不够严格
- 重量字段位置接近设计字段

**影响**: 中等，需人工核对

**建议**:
- 增强人名特征验证（2-4个汉字）
- 排除数字和小数点

### 3. 材料字段混淆（少数）

**问题**: 部分材料字段提取了图纸名称
- 示例: "前片主框架1", "焊接件"（应是Q235B等）

**原因**:
- 材料信息位置不统一
- 名称字段被误认为材料

**影响**: 轻微，大部分材料正确

**建议**: 优先提取符合材料代号格式的文本（QxxxB, 304等）

### 4. 公司名称OCR错误（少数）

**问题**: 公司名称有错别字
- 正确: `深圳市奇见科技有限公司`
- 错误: `之深圳市奇见科技有限公司`, `Z深圳市奇贝科技有限公司`

**原因**: OCR识别错误

**影响**: 轻微，名称基本可识别

**建议**:
- 后处理修正（去除前缀字符）
- 使用公司名称词典验证
