## 💡 核心发现

### 1. 装配图布局特征

**典型装配图的文字分布**：
```
TOP区域 (0-25%):    18% 文字块
  └─ 技术要求 (关键信息)

MIDDLE区域 (25-75%):  31% 文字块
  └─ 尺寸标注 (噪音)

BOTTOM区域 (75-100%): 50% 文字块
  └─ 标题栏 (关键信息)
```

### 2. 为什么单一底部过滤会失败？

❌ **错误假设**: "所有重要信息都在底部标题栏"

✅ **实际情况**:
- 技术要求在**顶部**（传统工程制图规范）
- 标题栏在**底部**（图纸右下角）
- 中间区域是尺寸标注（噪音）

### 3. 多区域过滤的优势

**智能识别关键区域**：
- 保留TOP：获取技术要求（18%文字）
- 过滤MIDDLE：去除尺寸标注噪音（31%文字）
- 保留BOTTOM：获取标题栏信息（50%文字）

**结果**：
- ✅ 保留68%文字块（TOP + BOTTOM）
- ❌ 过滤31%噪音（MIDDLE）
- ✅ 核心信息100%完整

## 🎯 最终推荐方案

### 装配图：多区域过滤策略 ⭐⭐⭐

**配置参数**：
```python
# 区域定义
top_percent = 0.25      # 保留顶部25%（技术要求）
middle_start = 0.25     # MIDDLE区域起始
middle_end = 0.75       # MIDDLE区域结束
bottom_percent = 0.75   # 保留底部25%（标题栏）

# 过滤逻辑
def filter_assembly_drawing(items):
    """装配图多区域过滤"""
    # 计算页面高度
    y_min, y_max = calculate_page_bounds(items)
    page_height = y_max - y_min

    # 阈值
    top_threshold = y_min + page_height * top_percent
    bottom_threshold = y_min + page_height * bottom_percent

    # 过滤
    filtered = []
    for item in items:
        center_y = item.center_y

        # 保留TOP或BOTTOM
        if center_y <= top_threshold or center_y >= bottom_threshold:
            filtered.append(item)

    return filtered
```

**预期效果**：
- 文字块减少：**30-35%** ✅
- 技术要求保留：**100%** ✅
- 图号材料公司：**100%** ✅
- BOM表保留：**95-100%** ✅
- JSONL文件缩小：**30-35%** ✅

**适用场景**：
- ✅ 装配图（含技术要求）
- ✅ 总图
- ✅ 系统图

## 📋 零件图方案

### 零件图：单一底部过滤 ⭐⭐

**配置参数**：
```python
# 零件图通常没有技术要求，或技术要求也在底部
bottom_percent = 0.35   # 保留底部35%

def filter_part_drawing(items):
    """零件图单一底部过滤"""
    y_min, y_max = calculate_page_bounds(items)
    page_height = y_max - y_min
    threshold = y_min + page_height * (1 - bottom_percent)

    return [item for item in items if item.center_y >= threshold]
```

**预期效果**：
- 文字块减少：**5-15%** （零件图文字本就少）
- 信息完整性：**95-100%**

**适用场景**：
- ✅ 零件图
- ✅ 简单图纸

## ⚠️ 注意事项

### 1. 技术要求位置可能变化

**问题**: 不同公司的图纸模板可能不同

**解决方案**:
- 测试样本时检查技术要求位置
- 如需要，调整`top_percent`参数（推荐0.20-0.30）

### 2. BOM表可能在中部

**问题**: 部分装配图BOM表在页面中部

**解决方案**:
- 如果BOM表丢失，可调整`middle_end`参数
- 或使用关键词检测（包含"序号"、"图号"、"数量"的区域保留）

### 3. 页面方向

**问题**: 横向/纵向图纸布局不同

**解决方案**:
- 先检测页面方向（宽 > 高 = 横向）
- 横向图纸可能需要不同的区域划分
