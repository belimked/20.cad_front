# AutoCAD 批量打印 - 截图+OCR方案说明

## 方案概述

由于窗口查找API在某些环境下不稳定，现改用 **截图+坐标估算** 方案来识别和点击批量打印对话框中的按钮。

## 工作流程

```
[步骤1] 启动 AutoCAD 并打开 DWG 文件
    ↓
[步骤2] 执行 BPLOT 命令
    ↓
[步骤3] 等待对话框出现（10秒）
    ↓
[步骤4] 获取 AutoCAD 窗口坐标
    ↓
[步骤5] 截取 AutoCAD 窗口到图片
    ↓
[步骤6] OCR识别（可选） / 坐标估算
    ↓
[步骤7] 点击估算的按钮位置
    ↓
[步骤8] 输入 "all" 并回车
```

## 核心改进

### 1. WaitForDialog() 函数

**旧方案（已废弃）：**
```vbscript
// 查找对话框窗口句柄
hwnd = Plugin.Window.Find(0, "批量打印")
// ❌ 问题：对话框标题可能不匹配，窗口类型不确定
```

**新方案（当前使用）：**
```vbscript
// 1. 获取 AutoCAD 窗口坐标
rect = Plugin.Window.GetWindowRect(acad_hwnd)

// 2. 截取窗口内容
Plugin.Window.ScreenShot(left, top, right, bottom, "C:\Temp\autocad_screenshot.bmp")

// 3. OCR识别（预留接口）或直接使用坐标估算
button_x = left + (right - left) * 0.3  // 窗口左侧 30% 位置
button_y = top + (bottom - top) * 0.45  // 窗口垂直 45% 位置
```

### 2. ClickSelectButton() 函数

**功能：**
- 优先使用手动配置的 `MANUAL_BUTTON_X` 和 `MANUAL_BUTTON_Y`
- 如果未配置，自动根据 AutoCAD 窗口尺寸估算按钮位置
- 点击前移动鼠标到目标位置，用户可以看到鼠标移动轨迹

**按钮位置估算公式：**
```
按钮X坐标 = 窗口左边界 + 窗口宽度 × 30%
按钮Y坐标 = 窗口上边界 + 窗口高度 × 45%
```

## 使用说明

### 快速开始

1. **第一次运行（测试模式）**
   ```
   运行脚本，观察鼠标移动到的位置
   如果位置不对，记录正确的按钮坐标
   ```

2. **配置正确坐标**
   ```vbscript
   // 在脚本第 74-75 行修改：
   Const MANUAL_BUTTON_X = 850    // 你的按钮X坐标
   Const MANUAL_BUTTON_Y = 520    // 你的按钮Y坐标
   ```

3. **正式运行**
   ```
   脚本将使用你配置的精确坐标
   不再需要估算，直接点击正确位置
   ```

#### 方法1：使用按键精灵的坐标查看功能
```
1. 打开按键精灵
2. 点击菜单"工具" → "取色/取坐标"
3. 移动鼠标到按钮上
4. 记录显示的坐标值
```

## OCR 集成（可选）

### 当前状态
脚本中预留了 OCR 接口，但默认使用坐标估算方案。

### 如何启用 OCR

如果你有按键精灵的 OCR 插件，可以在 `FindButtonByOCR()` 函数中启用：

```vbscript
Function FindButtonByOCR(image_path, offset_x, offset_y)
    // 方案1：使用按键精灵自带的 OCR 插件
    Dim ocr_text
    ocr_text = Plugin.Ocr.Recognize(image_path)

    // 搜索关键字
    If InStr(ocr_text, "选择批量打印图纸") > 0 Then
        // 找到了，返回坐标
        FindButtonByOCR = "850,520"  // 根据实际OCR结果计算
    Else
        FindButtonByOCR = ""
    End If
End Function
```

如果需要更准确的识别，可以集成：
- **百度OCR API**

## 常见问题

### Q1: 脚本点击位置不对怎么办？

**A:** 按照上面的方法获取正确坐标，配置 `MANUAL_BUTTON_X` 和 `MANUAL_BUTTON_Y`

### Q2: 截图失败怎么办？

**A:** 检查：
1. C:\Temp 目录是否有写入权限
2. AutoCAD 窗口是否被其他窗口遮挡
3. 窗口是否最小化

### Q3: 窗口坐标显示 0|0|0|0 怎么办？

**A:** 脚本会自动尝试使用 `GetClientRect()` 获取客户区坐标作为备用方案

### Q4: 能否支持多显示器？

**A:** 可以，坐标是绝对屏幕坐标，支持多显示器环境

## 性能对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **窗口查找API** | 快速，无需图像处理 | API兼容性问题，标题/类名不确定 | 环境稳定时 |
| **截图+坐标估算**（当前） | 稳定，兼容性好，易调试 | 需要配置坐标 | 推荐使用 |
| **截图+OCR识别** | 最灵活，适应界面变化 | 需要OCR插件，速度较慢 | 完全自动化需求 |
