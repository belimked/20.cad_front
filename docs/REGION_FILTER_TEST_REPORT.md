## ✅ 方法2: 后处理过滤方式测试

### 实现方式

先进行完整OCR识别,然后基于文字块坐标进行后处理过滤:

```python
def filter_by_region_post_process(jsonl_data: dict, y_threshold: float = 0.65):
    """
    过滤JSONL结果,只保留底部区域的文字块

    Args:
        jsonl_data: 完整的OCR结果
        y_threshold: 忽略顶部的百分比 (0.65 = 忽略顶部65%)

    Returns:
        过滤后的JSONL数据
    """
    items = jsonl_data['data']

    # 计算页面高度和阈值
    all_y = [p[1] for item in items for p in item['box']]
    y_min, y_max = min(all_y), max(all_y)
    page_height = y_max - y_min
    threshold_y = y_min + page_height * y_threshold

    # 过滤: 只保留中心Y坐标 >= threshold_y 的文字块
    filtered_items = []
    for item in items:
        center_y = sum(p[1] for p in item['box']) / 4
        if center_y >= threshold_y:
            filtered_items.append(item)

    # 返回过滤后的数据
    filtered_data = jsonl_data.copy()
    filtered_data['data'] = filtered_items
    return filtered_data
```
