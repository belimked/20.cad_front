## 🚀 核心功能特性

### 1. 问题缩减处理
```python
from src.service.common.question_reduction import advanced_simplify_question

# 支持三种缩减级别
result = advanced_simplify_question("找一下实验03以及实验41的相关信息", 
                                   reduction_level='advanced')
# 输出: "实验03、实验41"
```

**功能特点**:
- 🔧 **4个基础缩减函数**: 实验编号标准化、公司名称简化、工程属性提取、时间表达标准化
- ⚙️ **3种缩减级别**: basic(保守)、advanced(平衡)、aggressive(激进)
- 📊 **详细统计信息**: 缩减率、应用规则、处理时间等

### 2. 训练数据生成
```bash
# 生成SFT格式训练数据
curl -X POST "http://localhost:8000/api/generate/save-generated-data" \
  -d '{"business_type": "updateStaff", "count": 100, 
       "enable_question_reduction": true, "training_format": "sft"}'
```

**支持格式**:
- 📄 **Standard格式**: 包含原始问题、缩减问题、统计信息和元数据
- 🏷️ **Classification格式**: 适用于分类模型训练的标签化数据
- 💬 **SFT格式**: 适用于指令微调的对话格式数据

### 3. 质量评估体系
```python
from src.service.common.question_reduction import evaluate_reduction_quality

quality = evaluate_reduction_quality(original, reduced)
# 返回: {reduction_rate, key_info_retention_rate, semantic_similarity, 
#        readability_score, overall_quality}
```

**评估维度**:
- 📉 **缩减率**: 文本长度缩减比例
- 🔑 **关键信息保持率**: 重要信息保留程度  
- 🧠 **语义相似度**: 原文与缩减文本的语义相似性
- 📖 **可读性评分**: 缩减后文本的流畅度
- ⭐ **综合质量评分**: 加权平均的整体质量指标

### 4. 专项分析报告
```bash
# 生成分析报告
curl -X POST "http://localhost:8000/api/evaluation/question-reduction/analyze" \
  -d '{"reduction_data": [...], "generate_report": true}'
```

**报告内容**:
- 📈 **缩减效果统计**: 平均缩减率、分布分析
- 🔍 **规则应用分析**: 最常用规则、级别分布
- 📊 **质量分布分析**: 质量等级分类和百分比
- 💡 **改进建议**: 基于分析结果的智能建议
